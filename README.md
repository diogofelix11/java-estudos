# java-estudos

Exercícios e estudos de Java, lógica de programação e orientação a objetos.

## Organização

- **logica-programacao/beecrowd** — exercícios de lógica de programação resolvidos em Java, com foco em fundamentos, estruturas condicionais, laços de repetição, entrada e saída de dados e resolução de problemas.
- **poo** — exercícios de orientação a objetos em Java.

Este repositório acompanha minha evolução durante os estudos de Análise e Desenvolvimento de Sistemas e minha prática de programação em Java.
