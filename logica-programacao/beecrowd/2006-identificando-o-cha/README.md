# 2006 - Identificando o Chá

## O que o exercício pede

Leia o tipo de chá escolhido pelo participante e depois leia as respostas de **cinco participantes**.

O programa deve contar quantas respostas são iguais ao tipo de chá correto.

## O que foi praticado

- `Scanner`
- `for`
- `if`
- Comparação de valores
- Contador
- Repetição com quantidade definida de entradas

## Como resolvi

Primeiro, li o tipo de chá correto e armazenei o valor na variável `tipo`.

Depois, utilizei um `for` para ler as cinco respostas.

A cada resposta, comparo o valor recebido com `tipo`. Quando os valores são iguais, aumento o contador:

`contador++`

Depois que as cinco respostas são verificadas, mostro o valor do contador.

## Aprendizado

Este exercício reforçou o uso de um contador dentro de um laço e mostrou uma situação comum em programação: comparar várias entradas com um mesmo valor de referência.

## Código

A solução está no arquivo `Main.java`.
