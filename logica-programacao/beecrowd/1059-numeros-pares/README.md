# 1059 - Números Pares

## O que o exercício pede

Imprima todos os números pares de **2 até 100**, um número por linha.

## O que foi praticado

- Estrutura de repetição `for`
- Incremento
- Números pares
- Operador módulo (`%`)
- Controle do início, fim e passo de um laço

## Como resolvi

Neste exercício, percebi que não era necessário testar todos os números para descobrir quais são pares.

Comecei o `for` diretamente no número **2** e aumentei o valor de `i` de **2 em 2**:

`i += 2`

Dessa forma, o laço passa somente pelos números pares: 2, 4, 6, 8...

## Aprendizado

Este exercício ajudou a entender que o próprio funcionamento do `for` pode ser utilizado para simplificar a lógica, evitando verificações desnecessárias.

## Código

A solução está no arquivo `Main.java`.
