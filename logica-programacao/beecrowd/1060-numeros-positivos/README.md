# 1060 - Números Positivos

## O que o exercício pede

Leia **seis valores** e conte quantos deles são positivos.

Ao final, mostre a quantidade de valores positivos encontrados.

## O que foi praticado

- `Scanner`
- Estrutura de repetição `for`
- Estrutura condicional `if`
- Contador
- Comparação de valores
- Leitura de várias entradas sem criar uma variável para cada valor

## Como resolvi

Criei a variável `contador` começando em zero.

Depois, utilizei um `for` para repetir a leitura seis vezes. A cada repetição, um novo valor é armazenado na variável `valor`.

Quando o valor é maior que zero, aumento o contador:

`contador++`

No final do laço, o contador representa a quantidade de valores positivos que foram digitados.

## Aprendizado

Este exercício ajudou a entender a ideia de **contador** e mostrou como um `for` pode ser usado para processar várias entradas sem precisar criar seis variáveis diferentes.

## Código

A solução está no arquivo `Main.java`.
