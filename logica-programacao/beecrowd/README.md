# Lógica de Programação — Beecrowd

Exercícios resolvidos em Java para praticar lógica de programação, estruturas condicionais, estruturas de repetição, entrada e saída de dados e resolução de problemas.

Os exercícios estão organizados pelo número do problema do Beecrowd.

## Exercícios

- 1035 — Teste de Seleção 1
- 1040 — Média 3
- 1048 — Aumento de Salário
- 1059 — Números Pares
- 1060 — Números Positivos
- 1064 — Positivos e Média
- 1067 — Números Ímpares
- 1070 — Seis Números Ímpares
- 1071 — Soma de Ímpares Consecutivos
- 2006 — Identificando o Chá

Este diretório representa parte da minha prática de lógica de programação em Java e da minha evolução durante os estudos.
