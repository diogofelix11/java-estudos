# Conversor de Moeda

Exercício de fixação feito durante meus estudos de Java e orientação a objetos.

O programa recebe a cotação do dólar e a quantidade de dólares que será comprada. Depois, calcula o valor da compra em reais acrescentando o IOF de 6%.

## O que pratiquei

- Classes e métodos
- Membros estáticos (`static`)
- Constante `static final`
- Métodos estáticos
- Entrada de dados com `Scanner`
- Cálculos com `double`
- Organização de classes em pacotes

## Estrutura

- `Main` → responsável pela entrada dos dados e apresentação do resultado.
- `ConversorDeMoeda` → responsável pelo cálculo da conversão e do IOF.
