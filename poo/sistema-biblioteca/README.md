# Sistema de Biblioteca

## Sobre o exercício

O exercício consiste em desenvolver um pequeno sistema de biblioteca em Java, permitindo cadastrar e gerenciar até três livros por meio de um menu interativo.

O sistema permite cadastrar livros com diferentes níveis de informação, listar os livros cadastrados, consultar suas fichas, emprestar e devolver livros, avançar páginas e alterar os dados de um livro.

## Conceitos praticados

- Programação Orientada a Objetos (POO)
- Classes e objetos
- Encapsulamento
- Construtores e sobrecarga de construtores
- Getters e setters
- Sobrecarga de métodos
- Métodos com e sem retorno
- Validação de dados
- Estruturas condicionais e de repetição
- Organização do código em pacotes
- Uso da classe `LocalDate`

## Como desenvolvi

Criei a classe `Livro` para armazenar as informações e controlar as operações de cada livro, incluindo empréstimos, devoluções, progresso da leitura e validação dos dados.

Na classe `Main`, desenvolvi um menu interativo para permitir que o usuário utilize as funcionalidades da biblioteca. Também utilizei métodos auxiliares para organizar o código e construtores sobrecarregados para possibilitar diferentes formas de cadastrar um livro.

O exercício me ajudou a praticar o encapsulamento, a sobrecarga de métodos e construtores e a interação entre classes em Java.
